# Pack 04 · twin

Digital twin for style, decision priors, and relationship cards.

## Contracts

- Every twin answer includes citations.
- Confidence is surfaced explicitly.
- Retrieval is delegated to `packs/03-retrieval/api.py`.

## Data

- `data/twin/style.json`
- `data/twin/preferences.json`

If files do not exist, defaults are synthesized at runtime.
