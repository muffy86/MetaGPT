# Pack 06 · web3-frontier

Frontier adapter registry for decentralized agent frameworks and chain execution surfaces.

## Included

- `registry.py` — framework metadata + capability matrix
- `adapters/base.py` — adapter protocol
- `adapters/goat_adapter.py` — GOAT execution skeleton
- `adapters/agentkit_adapter.py` — Coinbase AgentKit execution skeleton
- `scripts/list_targets.py` — print shortlist and defaults

## Shortlist Coverage

- ElizaOS v2
- GOAT SDK
- Coinbase AgentKit (CDP)
- ARC
- Virtuals GAME
- Olas (Autonolas)
- ZerePy
- Mastra
- NEAR Shade Agents / Chain Signatures
